# Quantyra connectors

Open hardware connectors: editable CAD, printable meshes and practical print notes. Packaging **v1.0.0**; all dimensions are in **mm**.

| Component | Use | Print |
| --- | --- | --- |
| [Paired pin sleeve V2](connectors/paired-pin-sleeve/README.md) | Two straight LED leads contacting opposing individual male jumper pins | [STL](connectors/paired-pin-sleeve/stl/sleeve_pair_v2.stl) |

Choose the STL, slice, print, insert leads from opposite ends, and check operation. The enclosed V2 has a user-reported basic functional demonstration with a yellow LED that works and flashes.
